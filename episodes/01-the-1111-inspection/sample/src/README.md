# Cold-open sample: how it was made

68-second 1080p/24fps animatic of Scene 01 + title card. Everything is generated by code (no stock assets).

- `tts.py`: voice lines using Piper TTS (`pip install piper-tts`). Voice models go in `voices/`:
  `en_US-ryan-high` (narrator), `en_GB-alan-medium` (the voice outside), `en_US-lessac-medium` (Mara / DLI).
- `audio.py`: synthesises the drone, knocks, handle creak, stings and mixes the VO (about -14 LUFS, YouTube's target).
- `render.py`: draws every frame (Pillow + NumPy) and pipes them to ffmpeg with the soundtrack.
- `timeline.py`: all shot and cue timings in one place. Change a time here and both audio and video follow.

```bash
python3 tts.py && python3 audio.py && python3 render.py out.mp4
```
