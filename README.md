# youtube-content-help

Research and design for a gaming YouTube Thumbnail Intelligence system: research competitors, analyze thumbnails, generate concepts, QC, and learn from real channel performance.

- [`docs/01-system-research-and-architecture.md`](docs/01-system-research-and-architecture.md): GitHub repository evaluation, recommended components, risks, MVP architecture, implementation plan, unverified claims.
- [`docs/02-youtube-research-test.md`](docs/02-youtube-research-test.md): HasData YouTube MCP verification, outlier research across gaming categories, observed thumbnail patterns, five initial thumbnail directions.
- [`research/2026-10-26/`](research/2026-10-26/): evidence with provenance (video IDs, views, HasData request IDs), channel-baseline script and output, contact-sheet script.

Competitor thumbnail images are not stored in this repo; only their URLs are.
