# youtube-content-help

Production material for the **MeowDude** gaming tutorial channel.

- [`brand/`](brand/README.md): the MeowDude visual identity. Colour, type, layout, the mascot, annotation kit, UI props and animation direction. Start with `brand/README.md`.

Regenerate every brand SVG after changing shapes or colours:

```sh
python3 brand/tools/build_assets.py
```
